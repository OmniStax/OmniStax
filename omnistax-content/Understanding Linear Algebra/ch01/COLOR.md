# Chapter 1 colour

Refines the book's `COLOR.md`; no new hue. Prepared 2026-11-02 with `config.md`.

## By root rule 7's four ways

1. Facts: none. The author's diagrams colour nothing by its nature.
2. Conventions: none.
3. Referents: the lines and planes of one example that the text names apart (below).
4. Categories: `matrix` for A and B (1.3, 1.4), the augmented matrix, the coefficient matrix and a reduced row echelon matrix wherever a figure or a readout draws one as a whole, with its pivot positions highlighted in the same hue; `region` for a solution set drawn in a figure, the meeting point of two lines, the line where two planes meet, the point where three do, and the line y = 0 or the plane z = 0 as the solution set of one equation. Symbols: `A` and `B` wear `matrix` (`\kA`, `\kB`); `\sim` is ink.

Untyped, in ink: the unknowns x, y, z and x₁ … xₙ, the coefficients a₁ … aₙ, the constant b, the values s₁ … sₙ of a solution, the number of unknowns n and the size n of a square matrix, the entries of every matrix, the operation counts 2n³ + n², the parameters k, l, a, b, c of 1.4.6–1.4.7, the traffic flows and temperatures of 1.3's exercises, the polynomial p(x) and its coefficients in 1.4.9. The book's bold pivot entries are set bold, their colour `matrix`'s where a figure draws the matrix.
