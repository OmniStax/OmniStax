The vector closest to b

We know that a linear system $\kA\kvecx=\kvecb$ is inconsistent when $\kvecb$ is not in $\kCol(\kA)$, the column space of $\kA$. Later in this chapter, we’ll develop a strategy for dealing with inconsistent systems by finding $\kvecbhat$, the vector in $\kCol(\kA)$ that minimizes the distance to $\kvecb$. The equation $\kA\kvecx=\kvecbhat$ is therefore consistent and its solution set can provide us with useful information about the original system $\kA\kvecx=\kvecb$.

In this section and the next, we’ll develop some techniques that enable us to find $\kvecbhat$, the vector in a given subspace $\kW$ that is closest to a given vector $\kvecb$.

Introduction

We frequently ask to write a given vector as a linear combination of given basis vectors. In the past, we have done this by solving a linear system. The preview activity illustrates how this task can be simplified when the basis vectors are orthogonal to each other. We’ll explore this and other uses of orthogonal bases in this section.

Orthogonal sets

The preview activity dealt with a basis of ${\mathbb R}^2$ formed by two orthogonal vectors. More generally, we will consider a set of orthogonal vectors, as described in the next definition.

Definition 6.3.1

By an orthogonal set of vectors, we mean a set of nonzero vectors each of which is orthogonal to the others.

Example 6.3.2

The 3-dimensional vectors

$$ \kvecwone = \left[\begin{array}{r}1 \\ -1 \\ 1 \end{array}\right],\hspace{24pt} \kvecwtwo = \left[\begin{array}{r}1 \\ 1 \\ 0 \end{array}\right],\hspace{24pt} \kvecwthree = \left[\begin{array}{r}1 \\ -1 \\ -2 \end{array}\right]. $$

form an orthogonal set, which can be verified by computing

$$ \begin{array}{rcl} \kvecwone\cdot\kvecwtwo & {}={} & 0 \\ \kvecwone\cdot\kvecwthree & {}={} & 0 \\ \kvecwtwo\cdot\kvecwthree & {}={} & 0\text{.} \\ \end{array} $$

Notice that this set of vectors forms a basis for ${\mathbb R}^3$.

Example 6.3.3

The vectors

$$ \kvecwone = \left[\begin{array}{r}1 \\ 1 \\ 1 \\ 1 \end{array}\right],\hspace{24pt} \kvecwtwo = \left[\begin{array}{r}1 \\ 1 \\ -1 \\ -1 \end{array}\right],\hspace{24pt} \kvecwthree = \left[\begin{array}{r}1 \\ -1 \\ 1 \\ -1 \end{array}\right] $$

form an orthogonal set of 4-dimensional vectors. Since there are only three vectors, this set does not form a basis for ${\mathbb R}^4$. It does, however, form a basis for a 3-dimensional subspace $\kW$ of ${\mathbb R}^4$.

Suppose that a vector $\kvecb$ is a linear combination of an orthogonal set of vectors $\kvecwone,\kvecwtwo,\ldots,\kvecwn$; that is, suppose that

$$ c_1\kvecwone + c_2\kvecwtwo + \cdots + c_n\kvecwn = \kvecb. $$

Just as in the preview activity, we can find the weight $c_1$ by dotting both sides with $\kvecwone$ and applying the distributive property of dot products:

Notice how the presence of an orthogonal set causes most of the terms in the sum to vanish. In the same way, we find that

$$ c_i = \frac{\kvecb\cdot\kvecwi}{\kvecwi\cdot\kvecwi} $$

so that

$$ \kvecb = \frac{\kvecb\cdot\kvecwone}{\kvecwone\cdot\kvecwone}\kvecwone + \frac{\kvecb\cdot\kvecwtwo}{\kvecwtwo\cdot\kvecwtwo}\kvecwtwo + \cdots + \frac{\kvecb\cdot\kvecwn}{\kvecwn\cdot\kvecwn}\kvecwn\text{.} $$

We’ll record this fact in the following proposition.

Proposition 6.3.4

If a vector $\kvecb$ is a linear combination of an orthogonal set of vectors $\kvecwone,\kvecwtwo,\ldots,\kvecwn$, then

$$ \kvecb = \frac{\kvecb\cdot\kvecwone}{\kvecwone\cdot\kvecwone}\kvecwone + \frac{\kvecb\cdot\kvecwtwo}{\kvecwtwo\cdot\kvecwtwo}\kvecwtwo + \cdots + \frac{\kvecb\cdot\kvecwn}{\kvecwn\cdot\kvecwn}\kvecwn\text{.} $$

Using this proposition, we can see that an orthogonal set of vectors must be linearly independent. Suppose, for instance, that $\kvecwone,\kvecwtwo,\ldots,\kvecwn$ is a set of nonzero orthogonal vectors and that one of the vectors is a linear combination of the others, say,

$$ \kvecwthree = c_1\kvecwone + c_2\kvecwtwo\text{.} $$

We therefore know that

$$ \kvecwthree = \frac{\kvecwthree\cdot\kvecwone}{\kvecwone\cdot\kvecwone}\kvecwone + \frac{\kvecwthree\cdot\kvecwtwo}{\kvecwtwo\cdot\kvecwtwo}\kvecwtwo = \kveczero\text{,} $$

which cannot happen since we know that $\kvecwthree$ is nonzero. This tells us that

Proposition 6.3.5

An orthogonal set of vectors $\kvecwone,\kvecwtwo,\ldots,\kvecwn$ is linearly independent.

If the vectors in an orthogonal set have dimension $m$, they form a linearly independent set in ${\mathbb R}^m$ and are therefore a basis for the subspace $\kW=\kSpan\left\{\kvecwone,\kvecwtwo,\ldots,\kvecwn\right\}$. If there are $m$ vectors in the orthogonal set, they form a basis for ${\mathbb R}^m$.

This activity introduces an important way of modifying an orthogonal set so that the vectors in the set have unit length. Recall that we may multiply any nonzero vector $\kvecw$ by a scalar so that the new vector has length 1. For instance, we know that if $s$ is a positive scalar, then $\left|s\kvecw\right| = s\left|\kvecw\right|$. To obtain a vector $\kvecu$ having unit length, we want

$$ \left|\kvecu\right| = \left|s\kvecw\right| = s\left|\kvecw\right| = 1 $$

so that $s=1/\left|\kvecw\right|$. Therefore,

$$ \kvecu = \frac{1}{\left|\kvecw\right|}\kvecw $$

becomes a unit vector parallel to $\kvecw$.

Orthogonal sets in which the vectors have unit length are called orthonormal and are especially convenient.

Definition 6.3.6

An orthonormal set is an orthogonal set of vectors each of which has unit length.

Example 6.3.7

The vectors

$$ \kvecuone=\left[\begin{array}{r}1/\sqrt{2} \\ 1/\sqrt{2} \end{array}\right],\hspace{24pt} \kvecutwo=\left[\begin{array}{r}-1/\sqrt{2} \\ 1/\sqrt{2} \end{array}\right] $$

are an orthonormal set of vectors in ${\mathbb R}^2$ and form an orthonormal basis for ${\mathbb R}^2$.

If we form the matrix

$$ \kQ=\begin{bmatrix} \kvecuone & \kvecutwo \end{bmatrix} = \begin{bmatrix} 1/\sqrt{2} & -1/\sqrt{2} \\ 1/\sqrt{2} & 1/\sqrt{2} \\ \end{bmatrix}\text{,} $$

we find that $\kQT\kQ = \kI$ since Proposition 6.2.8 tells us that

$$ \kQT\kQ = \begin{bmatrix} \kvecuone\cdot\kvecuone & \kvecuone\cdot\kvecutwo \\ \kvecutwo\cdot\kvecuone & \kvecutwo\cdot\kvecutwo \\ \end{bmatrix} = \begin{bmatrix} 1 & 0 \\ 0 & 1 \\ \end{bmatrix} $$

The previous activity and example illustrate the next proposition.

Proposition 6.3.8

If the columns of the $m\times n$ matrix $\kQ$ form an orthonormal set, then $\kQT\kQ = \kIn$, the $n\times n$ identity matrix.

Orthogonal projections

We now turn to an important problem that will appear in many forms in the rest of our explorations. Suppose, as shown in Figure 6.3.9, that we have a subspace $\kW$ of ${\mathbb R}^m$ and a vector $\kvecb$ that is not in that subspace. We would like to find the vector $\kvecbhat$ in $\kW$ that is closest to $\kvecb$, meaning the distance between $\kvecbhat$ and $\kvecb$ is as small as possible.

To get started, let’s consider a simpler problem where we have a line $\kL$ in ${\mathbb R}^2$, defined by the vector $\kvecw$, and another vector $\kvecb$ that is not on the line, as shown on the left of Figure 6.3.10. We wish to find $\kvecbhat$, the vector on the line that is closest to $\kvecb$, as illustrated in the right of Figure 6.3.10.

To find $\kvecbhat$, we require that $\kvecb-\kvecbhat$ be orthogonal to $\kL$. For instance, if $\kvecy$ is another vector on the line, as shown in Figure 6.3.11, then the Pythagorean theorem implies that

$$ \left|\kvecb-\kvecy\right|^2 = |\kvecb-\kvecbhat|^2 + |\kvecbhat-\kvecy|^2 $$

which means that $\left|\kvecb-\kvecy\right|\geq|\kvecb-\kvecbhat|$. Therefore, $\kvecbhat$ is closer to $\kvecb$ than any other vector on the line $\kL$.

Definition 6.3.12

Given a vector $\kvecb$ in ${\mathbb R}^m$ and a subspace $\kW$ of ${\mathbb R}^m$, the orthogonal projection of $\kvecb$ onto $\kW$ is the vector $\kvecbhat$ in $\kW$ that is closest to $\kvecb$. It is characterized by the property that $\kvecb-\kvecbhat$ is orthogonal to $\kW$.

In all the cases considered in the activity, we are looking for $\kvecbhat$, the vector in a subspace $\kW$ closest to a vector $\kvecb$, which is found by requiring that $\kvecb-\kvecbhat$ be orthogonal to $\kW$. This means that $(\kvecb-\kvecbhat)\cdot\kvecw = 0$ for any vector $\kvecw$ in $\kW$.

Proposition 6.3.15 · Projection formula

If $\kW$ is a subspace of ${\mathbb R}^m$ having an orthogonal basis $\kvecwone,\kvecwtwo,\ldots, \kvecwn$ and $\kvecb$ is a vector in ${\mathbb R}^m$, then the orthogonal projection of $\kvecb$ onto $\kW$ is

$$ \kvecbhat= \frac{\kvecb\cdot\kvecwone}{\kvecwone\cdot\kvecwone}~\kvecwone + \frac{\kvecb\cdot\kvecwtwo}{\kvecwtwo\cdot\kvecwtwo}~\kvecwtwo + \cdots + \frac{\kvecb\cdot\kvecwn}{\kvecwn\cdot\kvecwn}~\kvecwn\text{.} $$
Summary · Caution

Remember that the projection formula given in Proposition 6.3.15 applies only when the basis $\kvecwone,\kvecwtwo,\cdots,\kvecwn$ of $\kW$ is orthogonal.

If we have an orthonormal basis $\kvecuone,\kvecutwo,\ldots,\kvecun$ for $\kW$, the projection formula simplifies to

$$ \kvecbhat= (\kvecb\cdot\kvecuone)~\kvecuone + (\kvecb\cdot\kvecutwo)~\kvecutwo + \cdots + (\kvecb\cdot\kvecun)~\kvecun\text{.} $$

$$ \kQ = \begin{bmatrix} \kvecuone & \kvecutwo & \ldots & \kvecun \end{bmatrix}\text{,} $$

Proposition 6.3.16

If $\kvecuone,\kvecutwo,\ldots,\kvecun$ is an orthonormal basis for a subspace $\kW$ of ${\mathbb R}^m$, then the matrix transformation that projects vectors in ${\mathbb R}^m$ orthogonally onto $\kW$ is represented by the matrix $\kP=\kQ\kQT$ where

$$ \kQ = \begin{bmatrix} \kvecuone & \kvecutwo & \ldots & \kvecun \\ \end{bmatrix}\text{.} $$

Example 6.3.17

In the previous activity, we looked at the plane $\kW$ defined by the two orthogonal vectors

$$ \kvecwone=\left[\begin{array}{r}2 \\ 2 \\ -1 \end{array}\right],\hspace{24pt} \kvecwtwo=\left[\begin{array}{r}1 \\ 0 \\ 2 \end{array}\right]\text{.} $$

We can form an orthonormal basis by scalar multiplying these vectors to have unit length:

$$ \kvecuone=\frac13\left[\begin{array}{r}2 \\ 2 \\ -1 \end{array}\right] = \left[\begin{array}{r}2/3 \\ 2/3 \\ -1/3 \end{array}\right],\hspace{24pt} \kvecutwo=\frac1{\sqrt{5}}\left[\begin{array}{r}1 \\ 0 \\ 2 \end{array}\right] = \left[\begin{array}{r}1/\sqrt{5} \\ 0 \\ 2/\sqrt{5} \end{array}\right]\text{.} $$

Using these vectors, we form the matrix

$$ \kQ = \begin{bmatrix} 2/3 & 1/\sqrt{5} \\ 2/3 & 0 \\ -1/3 & 2/\sqrt{5} \\ \end{bmatrix}\text{.} $$

The projection onto the plane $\kW$ is then given by the matrix

$$ \kQ\kQT = \begin{bmatrix} 2/3 & 1/\sqrt{5} \\ 2/3 & 0 \\ -1/3 & 2/\sqrt{5} \\ \end{bmatrix} \begin{bmatrix} 2/3 & 2/3 & -1/3 \\ 1/\sqrt{5} & 0 & 2/\sqrt{5} \\ \end{bmatrix} = \begin{bmatrix} {29}/{45} & {4}/{9} & {8}/{45} \\ {4}/{9} & {4}/{9} & -{2}/{9} \\ {8}/{45} & -{2}/{9} & {41}/{45} \end{bmatrix}\text{.} $$

Let’s check that this works by considering the vector $\kvecb=\left[\begin{array}{r}1 \\ 0 \\ 0 \end{array}\right]$ and finding $\kvecbhat$, its orthogonal projection onto the plane $\kW$. In terms of the original basis $\kvecwone$ and $\kvecwtwo$, the projection formula from Proposition 6.3.15 tells us that

$$ \kvecbhat=\frac{\kvecb\cdot\kvecwone} {\kvecwone\cdot\kvecwone}~\kvecwone + \frac{\kvecb\cdot\kvecwtwo} {\kvecwtwo\cdot\kvecwtwo}~\kvecwtwo = \left[\begin{array}{c}{29}/{45} \\ 4/9 \\ 8/{45} \end{array}\right] \\ $$

Alternatively, we use the matrix $\kQ\kQT$, as in Proposition 6.3.16, to find that

$$ \kvecbhat = \kQ\kQT\kvecb = \begin{bmatrix} {29}/{45} & {4}/{9} & {8}/{45} \\ {4}/{9} & {4}/{9} & -{2}/{9} \\ {8}/{45} & -{2}/{9} & {41}/{45} \end{bmatrix}\left[\begin{array}{r}1 \\ 0 \\ 0 \end{array}\right] = \left[\begin{array}{c}{29}/{45} \\ 4/9 \\ 8/{45} \end{array}\right]\text{.} $$

This activity demonstrates one issue of note. We found $\kvecbhat$, the orthogonal projection of $\kvecb$ onto $\kW$, by requiring that $\kvecb-\kvecbhat$ be orthogonal to $\kW$. In other words, $\kvecb-\kvecbhat$ is a vector in the orthogonal complement $\kWperp$, which we may denote $\kvecbperp$. This explains the following proposition, which is illustrated in Figure 6.3.19

Proposition 6.3.18

If $\kW$ is a subspace of ${\mathbb R}^n$ with orthogonal complement $\kWperp$, then any $n$-dimensional vector $\kvecb$ can be uniquely written as

$$ \kvecb = \kvecbhat + \kvecbperp $$

where $\kvecbhat$ is in $\kW$ and $\kvecbperp$ is in $\kWperp$. The vector $\kvecbhat$ is the orthogonal projection of $\kvecb$ onto $\kW$ and $\kvecbperp$ is the orthogonal projection of $\kvecb$ onto $\kWperp$.

Let’s summarize what we’ve found. If $\kQ$ is a matrix whose columns $\kvecuone, \kvecutwo,\ldots,\kvecun$ form an orthonormal set in ${\mathbb R}^m$, then

  • $\kQT\kQ = \kIn$, the $n\times n$ identity matrix, because this product computes the dot products between the columns of $\kQ$.
  • $\kQ\kQT$ is the matrix the projects vectors orthogonally onto $\kW$, the subspace of ${\mathbb R}^m$ spanned by $\kvecuone,\ldots,\kvecun$.

As we’ve said before, matrix multiplication depends on the order in which we multiply the matrices, and we see this clearly here.

Because $\kQT\kQ=\kI$, there is a temptation to say that $\kQ$ is invertible. This is usually not the case, however. Remember that an invertible matrix must be a square matrix, and the matrix $\kQ$ will only be square if $n=m$. In this case, there are $m$ vectors in the orthonormal set so the subspace $\kW$ spanned by the vectors $\kvecuone,\kvecutwo,\ldots,{\mathbf u}_m$ is ${\mathbb R}^m$. If $\kvecb$ is a vector in ${\mathbb R}^m$, then $\kvecbhat=\kQ\kQT\kvecb$ is the orthogonal projection of $\kvecb$ onto ${\mathbb R}^m$. In other words, $\kQ\kQT\kvecb$ is the closest vector in ${\mathbb R}^m$ to $\kvecb$, and this closest vector must be $\kvecb$ itself. Therefore, $\kQ\kQT\kvecb = \kvecb$, which means that $\kQ\kQT=\kI$. In this case, $\kQ$ is an invertible matrix.

Example 6.3.20

Consider the orthonormal set of vectors

$$ \kvecuone=\left[\begin{array}{r}1/\sqrt{3} \\ -1/\sqrt{3} \\ 1/\sqrt{3} \end{array}\right], \hspace{24pt} \kvecutwo=\left[\begin{array}{r}1/\sqrt{2} \\ 1/\sqrt{2} \\ 0 \end{array}\right] $$

and the matrix they define

$$ \kQ = \begin{bmatrix} 1/\sqrt{3} & 1/\sqrt{2} \\ -1/\sqrt{3} & 1/\sqrt{2} \\ 1/\sqrt{3} & 0 \\ \end{bmatrix}\text{.} $$

In this case, $\kvecuone$ and $\kvecutwo$ span a plane, a 2-dimensional subspace of ${\mathbb R}^3$. We know that $\kQT\kQ = I_2$ and $\kQ\kQT$ projects vectors orthogonally onto the plane. However, $\kQ$ is not a square matrix so it cannot be invertible.

Example 6.3.21

Now consider the orthonormal set of vectors

$$ \kvecuone=\left[\begin{array}{r}1/\sqrt{3} \\ -1/\sqrt{3} \\ 1/\sqrt{3} \end{array}\right], \hspace{24pt} \kvecutwo=\left[\begin{array}{r}1/\sqrt{2} \\ 1/\sqrt{2} \\ 0 \end{array}\right], \hspace{24pt} \kvecuthree=\left[\begin{array}{r}1/\sqrt{6} \\ -1/\sqrt{6} \\ -2/\sqrt{6} \end{array}\right] $$

and the matrix they define

$$ \kQ = \begin{bmatrix} 1/\sqrt{3} & 1/\sqrt{2} & 1/\sqrt{6} \\ -1/\sqrt{3} & 1/\sqrt{2} & -1/\sqrt{6} \\ 1/\sqrt{3} & 0 & -2/\sqrt{6} \\ \end{bmatrix}\text{.} $$

Here, $\kvecuone$, $\kvecutwo$, and $\kvecuthree$ form a basis for ${\mathbb R}^3$ so that both $\kQT\kQ=I_3$ and $\kQ\kQT=I_3$. Therefore, $\kQ$ is a square matrix and is invertible.

Moreover, since $\kQT\kQ = \kI$, we see that $\kQinv = \kQT$ so finding the inverse of $\kQ$ is as simple as writing its transpose. Matrices with this property are very special and will play an important role in our upcoming work. We will therefore give them a special name.

Definition 6.3.22

A square $m\times m$ matrix $\kQ$ whose columns form an orthonormal basis for ${\mathbb R}^m$ is called orthogonal.

This terminology can be a little confusing. We call a basis orthogonal if the basis vectors are orthogonal to one another. However, a matrix is orthogonal if the columns are orthogonal to one another and have unit length. It pays to keep this in mind when reading statements about orthogonal bases and orthogonal matrices. In the meantime, we record the following proposition.

Proposition 6.3.23

An orthogonal matrix $\kQ$ is invertible and its inverse $\kQinv = \kQT$.
